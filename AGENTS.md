# Publication policy
Until the owner explicitly lifts the pause, do not publish book access URLs, original Drive file/folder IDs, Telegram message links/IDs, source captions, inventories, provenance, or credentials.
This public repository contains only sanitized bibliographic records with opaque CAT identifiers.
Full sources and repository history belong in the private archive.
Do not restore source synchronization or copy files from the private archive into this repository.
Run python verify_public_privacy.py before publishing.
